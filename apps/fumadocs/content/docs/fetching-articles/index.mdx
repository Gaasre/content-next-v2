# Fetching Articles

This section covers everything you need to know about fetching articles from Content Next using the SDK in your Next.js application.

## Overview

The Content Next SDK provides two main methods for fetching articles:

- **`articles.list()`** - Fetch a paginated list of article summaries (without content)
- **`articles.getBySlug()`** - Fetch a complete article including full content

All fetching is done server-side using Next.js Server Components for optimal performance and SEO.

## Installation

```bash
npm install @content-next-v2/sdk
```

## Basic Setup

```tsx
import { ContentNextClient } from "@content-next-v2/sdk";

const client = new ContentNextClient({
  apiKey: process.env.CONTENT_API_KEY!,
});
```
